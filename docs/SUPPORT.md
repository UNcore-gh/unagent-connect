## 真实链路

独立临时 Hub + 独立临时 legacy Bridge + ai插件测试库：

1. Hub 向 UNagent 专用会话提交任务，execToken 仅经本机接口和设备存储传递，不进入提示词与 Vault 任务账本。
2. UNagent 使用 hub_connect 向 Codex 提交子任务，程序内等待让出本地执行名额和 Hub 执行名额。
3. Codex 通过本轮限权 MCP 向 Claude 提交子任务。
4. Claude 回答 FULL_CHAIN_OK，结果沿同一任务树返回。三个任务均 completed。
5. 临时服务已关闭；测试库原 Bridge 配对和原 Hub 设备配置已恢复。没有改动原有笔记或插件 data.json。

另在系统临时项目生成 connect-acceptance.txt，初始内容 phase=initial，返工为 phase=revised；原生 session ID 一致，回传产物经 Hub 实际路径和存在性检查。

## 2026-10-25 可靠性补充检查

- 修复适配器停止接口不返回时，取消及撤销请求无限等待的问题。原生停止等待默认最多 5 秒，超时保留 `cancel_requested` 和执行占位；并发取消共用正在等待的原生请求。
- 晚到的停止确认仅作用于原执行轮次。确认旧任务停止并重置后，旧确认不能取消新轮次。撤销同时处理相关任务，不被单个无响应的入口挡住。
- 独立项目 `npm run check`：106 项测试通过，包含上述无响应、并发取消、撤销、晚到确认和旧轮次隔离回归。另用真实 UNagent 适配器代码配合模拟原生接口，验证监督结束、凭证失效后仍能记录同一原生任务的停止终态，拒绝改换原生任务身份；这些不算五种 Agent 的原生取消实测。
- 插件 `type:check` 通过，Hub 接入的 2 个测试文件共 31 项通过。lint 为 0 错误、11 条现有警告（主要为品牌大小写、弃用的按钮 API 和设置搜索提示）。
- 独立包移出源码目录后，校验全部 2,617 个分发文件，临时回环 HTTP 服务启动并通过健康检查，随后关闭。没有替换原服务或迁移历史任务。
- 测试库中 `main.js`、`manifest.json`、`styles.css` 与当前插件工作树产物逐项一致。本次仅改独立 Hub，没有重新复制插件；当前 Obsidian CLI 不提供 `dev:cdp`，本次未确认已加载实例，不将文件一致等同于已重载或运行验收。
